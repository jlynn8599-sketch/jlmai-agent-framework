# v2.0.0 Provenance Release — Announcement

## Paragraph 1 — The release
JLMAIAGENT LLC is pleased to announce the v2.0.0 provenance release of the
JLMAI Agent Framework, released October 17, 2026. This release establishes
verifiable provenance for the framework: every artifact ships with SHA-256
checksums recorded in the release manifest, and every commit in the
repository's history is cryptographically signed.

## Paragraph 2 — Honest provenance
What sets this release apart is what it refuses to claim. The v2.0.0 manifest
documents exactly what was verified — and plainly marks what was not,
including test coverage and system-hardening details that remain unverified.
No forensic audit is claimed, because none has been performed. In an industry
full of inflated security claims, we chose the harder path: a provenance
record you can actually trust because it tells you its limits.
